# Mallet 🔨

A general purpose library for making SourceMod plugins for Team Fortress 2.

*We take no responsibility in the hammer emoji not being a Mallet.*

## Differences over the legacy Plugin branch.

`Mallet2` is a rewritten version of Mallet that uses SourceMod extensions to provide functionality and avoiding the need
to run a patched/modified SourceMod.

Using an extension also allows us to use more low level code and take advantage of more modern instruction sets letting some
functionality be sped up by multiple factors.
